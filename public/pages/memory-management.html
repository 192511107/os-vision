Theoretical Foundations of Memory Architecture

Key algorithmic principles simulated in Stage 3.

◆ Contiguous Dynamic Partitioning

Evaluation of First-Fit, Best-Fit, and Worst-Fit allocation schemes. Highlights trade-offs between internal fragmentation and search overhead.

◆ FIFO & Belady's Anomaly

Demonstrates that increasing physical page frames can paradoxically increase page fault counts under FIFO page replacement.

◆ Least Recently Used (LRU)

Stack-based approximation algorithm replacing the page untouched for the longest historical period. Complies with the inclusion property.

◆ Optimal Replacement (OPT)

Theoretical gold standard with clairvoyant lookahead knowledge. Establishes the lower bound of page faults for any given reference string.
